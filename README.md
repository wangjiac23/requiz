# requiz

> re · quiz —— 重复测验，再问一遍。给你一座趁手的题库。

- 版本：v1.2.0（CLI + Localhost 网页 + 多题库 + 公式渲染）
- 技术栈：Go + Obsidian Markdown + Agent(pi)
- 运行环境：CLI + Localhost

## 产品背景

对于学生来说，做题的第一步是读题；对于老师来说，做题的第一步是出题。

出题最常见的方式就是拿来别人出的题。别人出的题每年都在增加，有些成为经典，有些已经消失，可能对于老师来说这些题目大部分都是没新意的老题，但对于每一届的学生来说它们都是新题，用别人出的题已经足够了，实在没有必要自己出题。

**出题其实就是选题**。选题最重要的就是数量多、质量高的题目来源。最根本的是课本习题，最权威的是高考真题，其次是各地模考题，再次是机构练习题。

requiz 是一个**题库管理系统**，不是题库平台。题目不是目的，学习才是目的。

## 快速开始

```bash
# 构建
go build -o dist/requiz.exe ./src

# 1. 连接题库文件夹（demo/题库A 是带 .requiz 配置的演示题库）
./dist/requiz.exe connect "demo/题库A"

# 2. 列出题库中的题目（可跟目录参数；cd 进题库目录后可省略）
./dist/requiz.exe list demo/题库A

# 3. 读取单题全文
./dist/requiz.exe read M001 demo/题库A

# 4. 按需显示（缺省显示题干；可用 --a/--e/--n 组合）
./dist/requiz.exe view M001 demo/题库A --a --e

# 5. 启动 localhost 网页服务（v1.0.0 → v1.1.0 多题库 + 三栏 UI）
./dist/requiz.exe serve demo/题库A -port 8080
# 浏览器打开 http://127.0.0.1:8080/ ：
#   顶部栏 ⚙ 设置 → 添加链接题库（写入 demo/题库A/.requiz/config.yaml 的 links）
#   下拉栏切换题库；左侧边栏浏览题目包；上边栏按标签筛选
# JSON API：/api/banks、/api/tree、/api/questions?tag=知识点&value=xxx、/api/question?id=
```

## 题目文件格式

一个题目就是一个 Markdown 笔记，YAML 元数据（系统属性 + 可选属性）+ 二级标题结构：

```markdown
---
app: requiz            # 运行软件（系统属性）
bank: math             # 所属题库（系统属性）
id: M001               # 题目编号（系统属性）
path: 题册/题组/题目.md # 路径（系统属性）
章节: 第一章            # 以下为可选属性
年级: 高一
难度: ★★
重要性: 必做经典题
来源: 课本习题
知识点: 集合
题型: 选择题
---

## 题目
题干内容……

## 答案
答案内容……

## 解析
解析内容……

## 备注
备注内容……
```

## 目录约定

- `data/` 只存放题库（原始素材，不含配置）；`demo/` 从 data 选取题目作为演示题库
- `.requiz/` 连接配置仅存在于可连接的题库目录下（如 `demo/.requiz/`）
- 一个题库建议收纳不超过 3000 道题，尽量少而精
- 题库层级不超过三层：**题库 → 题册 → 题组 → 题目**
- 题组（一个章节 / 一套题）10~30 道
- 题册（高一上 / 专题）10~30 个题组
- 题库 5~15 个题册
