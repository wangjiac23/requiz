## 题目

设

$$f(x) = \begin{cases} e^{1/x}, & x \ne 0 \\ 0, & x = 0 \end{cases}$$

讨论函数 $f(x)$ 的连续性，并求 $f(x)$ 的单调区间、极值点与极值、凸性区间、拐点和渐近线。

## 答案

- 连续性：唯一间断点 $x = 0$（第二类间断点，无穷间断点）；
- 单调区间：在 $(-\infty, 0)$ 与 $(0, +\infty)$ 上均单调下降；
- 极值：无极值点，从而无极值；
- 凸性区间：$(-\infty, -\frac{1}{2})$ 上凸，$(-\frac{1}{2}, 0)$ 与 $(0, +\infty)$ 均下凸；
- 拐点：唯一拐点 $x = -\frac{1}{2}$；
- 渐近线：垂直渐近线 $x = 0$，水平渐近线 $y = 1$。

## 解析

显然 $f(x)$ 有唯一可能的间断点 $x = 0$。对于 $x \ne 0$，$f(x)$ 无穷次可微，计算得

$$f'(x) = -\frac{1}{x^2}e^{1/x},\qquad f''(x) = \frac{1}{x^4}e^{1/x}(1 + 2x)$$

由此：

(i) **连续性**：$\lim_{x\to 0^-}e^{1/x} = 0 = f(0)$，但 $\lim_{x\to 0^+}e^{1/x} = +\infty$，故 $x = 0$ 是唯一间断点（无穷间断点，即第二类间断点）。

(ii) **单调性**：$x \ne 0$ 时 $f'(x) = -\frac{e^{1/x}}{x^2} < 0$，故函数在 $(-\infty, 0)$ 和 $(0, +\infty)$ 上均单调下降。

(iii) **极值**：$f'$ 处处为负、无零点，故函数无极值点，从而无极值。

(iv) **凸性**：$f''(x) = \frac{e^{1/x}}{x^4}(1+2x)$。当 $x < -\frac{1}{2}$ 时 $f'' < 0$，函数上凸；当 $-\frac{1}{2} < x < 0$ 或 $x > 0$ 时 $f'' > 0$，函数下凸。故函数有唯一拐点 $x = -\frac{1}{2}$。

(v) **渐近线**：$\lim_{x\to 0^+}e^{1/x} = +\infty$，故 $x = 0$ 是垂直渐近线；$\lim_{x\to\pm\infty}e^{1/x} = e^0 = 1$，故 $y = 1$ 是水平渐近线。

## 备注

分段点处需用左右极限判断连续性；凸性记号"上凸 / 下凸"按本教材约定（也可称"凸 / 凹"）。
