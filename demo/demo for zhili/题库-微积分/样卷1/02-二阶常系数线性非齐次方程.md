## 题目

二阶线性常系数常微分方程 $y'' - 2y' + y = 2$ 的通解为 ____。

## 答案

$y = C_1 e^x + C_2 x e^x + 2$（$C_1, C_2$ 为任意常数）。

## 解析

特征方程为 $r^2 - 2r + 1 = (r-1)^2 = 0$，得二重特征根 $r = 1$，对应齐次方程 $y'' - 2y' + y = 0$ 的通解为 $C_1 e^x + C_2 x e^x$。

设特解 $y^* = A$（常数），代入原方程得 $A = 2$。故通解为

$$y = C_1 e^x + C_2 x e^x + 2$$

## 备注

重根情形齐次通解含 $xe^x$ 项；非齐次项为常数时特解可设为常数。
