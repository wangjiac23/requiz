## 题目

求常微分方程的初值问题

$$\sqrt{1 + y'^2} = (1-x)y'',\qquad y(0) = 0,\quad y'(0) = 0$$

的解。

## 答案

$y = -\ln\sqrt{1-x} + \frac{x^2}{4} - \frac{x}{2}$（也可写作 $y = \ln\frac{1}{\sqrt{1-x}} + \frac{x^2}{4} - \frac{x}{2}$）。

## 解析

这是一个可降阶方程（方程中不含 $y$）。令 $z = y'$，则方程可写作一阶方程

$$\sqrt{1 + z^2} = (1-x)z',\qquad z(0) = 0$$

分离变量得 $\frac{dz}{\sqrt{1+z^2}} = \frac{dx}{1-x}$。积分得

$$\ln\left(z + \sqrt{1+z^2}\right) = -\ln|1-x| + C_1$$

即 $(z + \sqrt{1+z^2})(1-x) = C_2$。由初值条件 $z(0) = 0$ 得 $C_2 = 1$，由此得到关于 $y'$ 的方程

$$y' + \sqrt{1 + y'^2} = \frac{1}{1-x}$$

即 $\sqrt{1 + y'^2} = \frac{1}{1-x} - y'$。两边平方得

$$1 + y'^2 = \frac{1}{(1-x)^2} - \frac{2y'}{1-x} + y'^2$$

化简得 $y' = \frac{1}{2(1-x)} - \frac{1-x}{2}$。再积分得

$$y = -\ln\sqrt{1-x} + \frac{x^2}{4} - \frac{x}{2} + C$$

由初值条件 $y(0) = 0$ 知 $C = 0$。故所求初值问题的解为

$$y = -\ln\sqrt{1-x} + \frac{x^2}{4} - \frac{x}{2}$$

## 备注

不含 $y$ 的二阶方程令 $z = y'$ 降为一阶；验证时注意 $\ln(z+\sqrt{1+z^2})$ 是 $\frac{dz}{\sqrt{1+z^2}}$ 的原函数。
