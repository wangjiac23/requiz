## 题目

设曲线段 $\Gamma$ 为圆心在点 $(0,1)$ 的单位圆周位于正方形 $0 \le x \le 1$，$0 \le y \le 1$ 的部分，平面区域 $D$ 为由 $\Gamma$、$x$ 轴以及直线 $x = 1$ 围成的有界区域（原卷含示意图）。

（I）求区域 $D$ 绕 $x$ 轴旋转一周所产生的旋转体体积；
（II）求曲线段 $\Gamma$ 绕 $x$ 轴旋转一周所产生的旋转面面积。

## 答案

（I）旋转体体积 $V = \frac{5\pi}{3} - \frac{\pi^2}{2}$；
（II）旋转面面积 $S = \pi^2 - 2\pi$。

## 解析

圆心在点 $(0,1)$ 的单位圆周位于正方形 $0 \le x \le 1$，$0 \le y \le 1$ 的部分可表示为函数

$$y = 1 - \sqrt{1 - x^2}$$

在区间 $[0,1]$ 上的图像。

**（I）旋转体体积**：由旋转体体积公式，

$$V = \int_0^1 \pi\,y(x)^2\,dx = \pi\int_0^1\left(1 - 2\sqrt{1-x^2} + 1 - x^2\right)dx = \pi\left(2 - \frac{1}{3}\right) - 2\pi\int_0^1\sqrt{1-x^2}\,dx$$

其中 $\int_0^1\sqrt{1-x^2}\,dx = \frac{\pi}{4}$（四分之一单位圆面积）。故

$$V = \frac{5\pi}{3} - 2\pi\cdot\frac{\pi}{4} = \frac{5\pi}{3} - \frac{\pi^2}{2}$$

**（II）旋转面面积**：由旋转面面积公式，

$$S = \int_0^1 2\pi y\,dL = 2\pi\int_0^1\left(1 - \sqrt{1-x^2}\right)\sqrt{1+y'^2}\,dx$$

由 $y' = \frac{x}{\sqrt{1-x^2}}$ 得 $\sqrt{1+y'^2} = \frac{1}{\sqrt{1-x^2}}$，于是

$$S = 2\pi\int_0^1\left(1 - \sqrt{1-x^2}\right)\frac{dx}{\sqrt{1-x^2}} = 2\pi\int_0^1\frac{dx}{\sqrt{1-x^2}} - 2\pi\int_0^1 dx = 2\pi\cdot\frac{\pi}{2} - 2\pi = \pi^2 - 2\pi$$

## 备注

$\int_0^1\frac{dx}{\sqrt{1-x^2}} = \arcsin x\Big|_0^1 = \frac{\pi}{2}$；旋转面面积用微元 $2\pi y\,dL$，注意 $dL = \sqrt{1+y'^2}dx$。
