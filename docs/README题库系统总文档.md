## 二、产品文档（最新版本）（面向小白用户）
### 2.1 产品介绍（README）
#### 2.1.1 一句话
#### 2.1.2 项目背景
对于学生来说，做题的第一步是读题；对于老师来说，做题的第一步是出题。

出题最常见的方式就是拿来别人出的题。别人出的题每年都在增加，有些成为经典，有些已经消失，可能对于老师来说这些题目大部分都是没新意的老题，但对于每一届的学生来说它们都是新题，用别人出的题已经足够了，实在没有必要自己出题。

基于此，出题其实就是选题。选题最重要的是数量多、质量高的题目来源，或者说题库。最根本的是课本习题，最权威的是高考真题。其次是各地教育局、学校和出题机构原创的的模考题，再次就是市面教育机构原创的练习题等。

明确了目标题库，下一步是获取这些题目。课本习题在课本上，高考真题在网络也很容易获取。模考题、练习题的一个获取途径是购买教辅资料，特别是练习册，这也是我推荐的方法。另一个获取途径就是关注一些公众号，他们会搜集各地的考题并整理推送。除此之外，网络还有一些线上题库等等。

### 2.2 快速开始
```bash
# 构建
go build -o dist/requiz.exe ./src

# 1. 连接题库文件夹（demo/题库A 是带 .requiz 配置的演示题库）
./dist/requiz.exe connect "demo/题库A"

# 2. 列出题库中的题目（可跟目录参数；cd 进题库目录后可省略）
./dist/requiz.exe list demo/题库A

# 3. 读取单题全文
./dist/requiz.exe read M001 demo/题库A

# 4. 按需显示（缺省显示题干；可用 --a/--e/--n 组合）
./dist/requiz.exe view M001 demo/题库A --a --e

# 5. 启动 localhost 网页服务（v1.0.0）
./dist/requiz.exe serve demo/题库A -port 8080
# 浏览器打开 http://127.0.0.1:8080/ 查看题库
# JSON API：http://127.0.0.1:8080/api/questions
```
### 2.3 产品内容
#### 2.3.1 题目文件格式
1. 一个题目就是一个md笔记
2. YAML数据：系统属性+自定义属性
3. 系统属性：运行软件、所属题库、id、路径
4. 可选系统属性：章节（可选）、年级（可选）、难度（可选）、重要新（可选）、来源（可选）、知识点（可选）、题型（可选）
5. 题目结构：二级标题，三级标题（可选）
#### 2.3.2 题库目录结构
1. 本地题库是一个包含md题目文件的文件夹，该文件夹结构如下
	题库A
		题目分组（多层自定义）
			题目
	题库B
2. 题库默认结构如下：
	题库
		题册
			题组
				题目
3. 综合考虑题库的维护成本和大脑学习效率，题库按需创建，建议一个科目对应一个题目；题目尽量少而精，单个题库的题目数量限制在一定范围；分组使用扁平结构，题库-题目的层级不建议超过五层。具体情况具体分析。
